# 动态对话标题测试集 (`tests/test-cases.md`)

本测试集覆盖 `dynamic-chat-title` Skill 的 **10 大核心评估场景与边界条件**，用于验证模型在各种上下文演化下的判断准确性与宿主兼容表现。

---

## TC-01：对话主题始终不变 ➔ 不重命名 (`KEEP`)

- **输入上下文**：
  - **当前标题**：「`Python 列表推导式与循环优化`」
  - **历史摘要**：第 1～6 轮一直在讨论如何用列表推导式替代繁琐的 `for` 循环，并对比了执行耗时。
  - **当前轮输入**：「如果列表里嵌套了字典，推导式里怎么加 `if` 过滤条件？」
- **预期决策**：`KEEP`
- **预期输出标题**：保持「`Python 列表推导式与循环优化`」不变。
- **通过标准**：识别出当前问题仍是原主题的自然延伸，不产生任何改名动作或改名提示。

- **预期决策**：`RENAME_ADVISORY`
- **预期输出标题**：「`开发动态对话标题 Skill`」
- **通过标准**：
